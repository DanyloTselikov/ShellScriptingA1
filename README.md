calc.sh - Whole Number Calculator 

Takes two non-negative whole numbers as command-line arguments and outputs their sum, difference, product, quotient, remainder, comparison, even/odd status, and Greatest Common Divisor (GCD). 

Syntax: 

./calc.sh <number1> <number2> 
 

Example: 

./calc.sh 12 18 
 

Notes: 

Both arguments must be valid whole numbers (0 or positive integers). 

If the second number is 0, the script safely skips division and prints a warning message.
